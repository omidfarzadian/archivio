
# Mava

**ماوا**

A simple personal data management app built for my dad. ❤️

One day, my dad needed a simple app to store and organize his personal information and files, so I decided to build one.

Mava was designed and implemented in a single day, almost entirely with the help of AI.

## Features

* 📁 Categories
* 📝 Notes and information
* 📎 File attachments
* 🔍 Local search
* 💾 Backup & restore
* 🌐 English & Persian support
* 🔒 Fully offline (no backend or cloud)

## Tech Stack

* React + TypeScript + Vite
* Capacitor
* SQLite
* Tailwind CSS
